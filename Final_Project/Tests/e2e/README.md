# בדיקות קצה-לקצה (end-to-end)

בדיקות שמריצות את `assembler` על קבצי `.as` שלמים ומשוות את קבצי הפלט
(`.am` / `.ob` / `.ent` / `.ext`) לקבצים צפויים. מכסות את כל השרשרת:

    pre_assembler → first_pass → second_pass → output

התיקייה הזו משמשת גם כמערכת הבדיקות האוטומטית וגם כדוגמאות הרצה
להדגמה/הגשה - זה אותו קלט ואותו פלט אמיתי, פשוט משמש לשתי מטרות.

## מבנה

```
Tests/e2e/
├── valids/              קבצי קלט תקינים
│   ├── valid_basic.as
│   ├── valid_data.as
│   ├── valid_extern.as
│   ├── valid_macro.as
│   └── expected/        הפלט הצפוי (.am/.ob/.ent/.ext) לכל קובץ
├── errors/               קבצי קלט עם שגיאות
│   ├── error_macro.as
│   ├── error_symbols.as
│   ├── error_syntax.as
│   ├── expected/         רשימת השגיאות הצפויה (.errors.txt) לכל קובץ
│   └── screen_output/    תדפיס מדויק של מה שהאסמבלר מדפיס בפועל
├── run_e2e.sh
├── run_check.sh
└── run_expect.sh
```

## הרצה

```bash
bash Tests/e2e/run_e2e.sh              # כל הבדיקות
bash Tests/e2e/run_e2e.sh valid_data   # בדיקה אחת (לפי שם, בכל אחת מהתתי-תיקיות)
bash Tests/e2e/run_e2e.sh --bless      # רישום הפלט הנוכחי כצפוי
```

הסקריפט לא נוגע בקבצי מקור ולא כותב לתוך `Tests/` מלבד `expected/` בזמן
`--bless` - כל הרצה רגילה מתבצעת בתיקייה זמנית. קוד יציאה 0 = הכל עבר.

## מקרי הבדיקה

| קובץ | תיקייה | מה נבדק |
|---|---|---|
| `valid_basic.as` | `valids/` | הוראות מכל 6 הסוגים (R_A, R_C, I_A, I_B, I_M, J), תוויות, `.entry` |
| `valid_data.as` | `valids/` | `.db` / `.dh` / `.dw` / `.asciz`, ערכי קצה, יישור כתובות |
| `valid_macro.as` | `valids/` | הגדרת מאקרו, פריסה חוזרת, מאקרו רב-שורות |
| `valid_extern.as` | `valids/` | `.extern` ויצירת `.ext` עם כל מקומות השימוש |
| `error_macro.as` | `errors/` | שגיאות פרה-אסמבלר: שם מקרו זהה לפקודה, לא מתחיל באות, תו לא חוקי, טקסט מיותר, מקרו כפול |
| `error_symbols.as` | `errors/` | שימוש בסמל שלא הוגדר |
| `error_syntax.as` | `errors/` | מספר אופרנדים שגוי, רגיסטר לא חוקי, מספר מחוץ לטווח, פסיקים, שם label לא חוקי, `.asciz` בלי גרשיים |

קובץ ב-`errors/` **חייב** לדווח שגיאות, ו**אסור** שייווצרו עבורו קבצי
`.ob`/`.ent`/`.ext`. רשימת השגיאות עצמה מושווית ל-`errors/expected/*.errors.txt`,
כדי שרגרסיה תתגלה.

## `screen_output/` - דוגמה לתדפיס מסך

לכל קובץ ב-`errors/` יש קובץ טקסט תואם תחת `screen_output/`, עם הפלט
המדויק שהאסמבלר הדפיס בפועל בהרצה אמיתית (לא נכתב ידנית). אם צריך תדפיס
מסך אמיתי (תמונה) להגשה, מריצים למשל `./assembler error_syntax.as`
במסוף אמיתי ומצלמים - התוכן זהה למה שכתוב כאן.

## עדכון הבסיס (`--bless`)

```bash
bash Tests/e2e/run_e2e.sh --bless
```

**חשוב:** `--bless` רק מצלם את הפלט הנוכחי. צריך לעבור על הקבצים ידנית
ולוודא שהם באמת נכונים לפני שסומכים עליהם - אחרת מקבעים באג כ"התנהגות צפויה".
